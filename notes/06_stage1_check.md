# Stage 1 結果の検証と Stage 2 GO 判定

日付: 2026-08-23。対象: `notes/05_stage1_measurement.md` と `results/stage1_*.csv`。
方法: `data/stage1/main_obs.parquet`（31,824 観測）からの独立再推定。
コード: 本ノートの計算は Cowork セッション側で実行（クレーム固定効果つきロジスティック、
per-k ノンパラ係数、fold 条件による α* 再計算）。

## 1. 再現の確認

- 変法 A（自己状態なし）: c₀=0.725, β_T=0.419, β_F=−0.568 — 05 の CSV と一致。
- 変法 B（自己状態あり）: c₀=−0.758, θ=1.909, β_T=0.291, β_F=−0.326 — 一致
  （多スタートで最適化した場合のみ。θ の尤度面は平坦で、初期値によっては劣った
  局所解に止まる。GX10 側の推定は正しい方に到達している）。
- notes/05 の記述と数値の内部矛盾は見つからなかった。§7 の未決 1（極性と真偽の交絡）は
  数値では解消できない設計上の制約で、そのまま Stage 2 に持ち越しが正しい。

## 2. 検証の本体: α* は縮約則の選び方に頑健か

05 §6 の α* は定数 β の則で計算されているが、05 §5 は β の強い k 依存（飽和）を
検出している。そこで三つの則で α* を再計算した:
(i) 定数 β、(ii) divisive β/(1+γk)（再フィット: A は β_T=1.45, β_F=−3.03, γ=0.53;
B は β_T=2.71, β_F=−4.14, γ=1.32, θ=2.15）、(iii) per-k ノンパラ係数を直接使用
（k∈{1,2,3,5,8,12} の実測値、対数-対数補間、k>12 はべき外挿と平坦外挿の両方）。

| 則 | 変法 A: α* | 変法 B: α* |
|---|---|---|
| 定数 β（05 §6 と同じ） | 0.40 | 0.46 |
| divisive | 0.46 | **1.27** |
| per-k 実測（べき外挿） | 0.46 | **1.33** |
| per-k 実測（平坦外挿） | 0.46 | — |

主要な帰結が二つある。

1. **変法 A（El et al. 型プロンプト）の α* ≈ 0.40–0.46 は縮約則の選択に頑健。**
   05 の判定「α* は窓に入る、ただし下端寄り」は飽和を考慮しても成立する。
   外挿方式（べき/平坦）にも依存しない。x_c の位置も三則で 0.39–0.44（α=0.3）
   → 0.33–0.34（α=0.4）と整合し、崩壊直前の移動幅は約 0.07。
2. **変法 B は則によって α* が 0.46 と 1.3 に割れる。**自己保持 θ≈2.15 のもとでは、
   結合が定数なら次数の減少とともに双安定が早く消えるが、飽和型なら社会入力の
   総量が次数に鈍感になり、θ が双安定を α≈1.3 まで支える。
   **この不一致は欠陥ではなく判別実験になる**: 変法 B で α を 0.6–1.3 の範囲で振れば、
   観測される committor 縮退の位置が定数則と飽和則を直接判別する。
   変法 A ではどの則でも同じ予測になるため、この判別は原理的にできない。

## 3. Stage 2 GO 判定と設計への反映

**判定: GO。**ただし 05 の 3 回答に以下を追補する。

1. **主実験は変法 A（El et al. プロトコル準拠、open decision どおり）**。
   予測: α* = 0.43 ± 0.03（則の不確かさ）。双安定区間が [〜0.15, 0.45] と狭いので、
   α 水準は旧計画の 3 水準等間隔ではなく **[0.20, 0.55] に集中配置**する
   （例: 0.20 / 0.30 / 0.38 / 0.45 / 0.55 + 対照 1.0）。α=0.20 の E[K] ≈ 10 は
   測定済み範囲（k ≤ 12）に収まる。主観測量は α* をまたぐ committor 縮退
   （α > α* で任意の x₀ から正答収束）で、x_c の移動（〜0.07）は副次。
2. **第二アーム: 変法 B（自己状態 1 行あり）を α ∈ {0.6, 0.9, 1.3} で追加**。
   ここは定数則が「単安定（縮退済み）」、飽和則が「双安定」を予測する領域で、
   どちらが観測されても縮約則が一つ決まる。第二アームは 3 水準 × committor 1 本で
   済むため、追加コストは主実験の約 1/3。
3. スループットは 05 §7-6 の実測（0.21 s/call、並列 8）で全予算を再計算すること。
4. 持ち越しの制約（05 §7 のとおり): 真偽非対称は本クレーム集合では未識別
   （16/17 REFUTES）。Stage 2 の主張は「正答側/誤答側」の言葉では書けるが
   「真/偽」の言葉では書けない。SUPPORTS 均衡集合は llama3.1:8b では場の較正と
   両立しない見込みが高く、モデル追加（qwen 系など）を検討する場合の第一の理由は
   ここになる。あわせて h_q 較正は本番プロンプトの完全な足場で行うこと（05 §7-2）。

## 4. 限界

- 本検証の per-k 係数は点推定で、CI は付けていない（05 の cluster bootstrap は
  定数則のみ）。ただし α* の頑健性は三則の一致で示しており、係数の標本誤差が
  α* に与える影響は 05 §6 の仕様間差（0.35–0.47）と同程度と見込まれる。
- k > 12 の外挿は α < 0.2 では効き始める。α 水準を 0.20 未満に下げるなら
  k = 16–20 の測定点を Stage 1 に追補する必要がある。
- 変法 B の θ は「明示的自己状態 1 行」の効果であり、Stage 2 の相互作用でエージェントが
  実現する持続性と同じである保証はない（05 §7-5 の開いた問いのまま）。第二アームの
  結果はこの問いにも同時に答える。

## 5. 主張

Stage 1 は Stage 2 の関門をすべて通過した。α* は縮約則の不確かさに対して
変法 A で頑健（0.43 ± 0.03）であり、実験窓内にある。さらに、縮約則の不確かさが
最大になる場所（変法 B、α 0.6–1.3）は回避すべき弱点ではなく、則を判別する
第二アームとして設計に取り込める。Stage 2 の設計は「α 掃引で縮退を検出する主実験
（変法 A、α ∈ [0.2, 0.55] 集中）+ 則判別の第二アーム（変法 B、α ∈ {0.6, 0.9, 1.3}）」
の二本立てとするのが、この測定結果に忠実な形である。
