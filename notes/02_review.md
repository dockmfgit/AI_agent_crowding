# Stage 0.5 対抗検証（adversarial review）

日付: 2026-08-22。対象: `notes/01_findings.md` と `scripts/01–04`。
方法: (a) `data/groups.parquet` からの独立再計算、(b) 生 JSON からの新規回帰、
(c) `lib/datagen/{dynamics,samplers}.py` のプロトコル読解。モードは A（実証報告）。

結論を先に書く。**Stage 0.5 が推定した x_c_empirical は committor 閾値ではなく、
問題難度の周辺要約である。比較相手の x_c_HMF は w_T=1 で不連続かつそれ以外で平坦なため、
分解能は「0.5 か 0.27 か」の 1 ビットしかない。したがって §3–§4 の Δx_c 表は、
理論の検証としては読めない。**ただし検証の過程で、HMF に入れるべき係数
（θ、w_T、負ラベル減衰 λ）をメッセージ水準で直接測る手順が得られた。これは Stage 1 に流用できる。

## A. 検証で残った指摘

### A-1. x_c_empirical は committor ではない — 分散のほとんどが問題間にある

x0 の分散のうち問題間成分が占める割合、および問題内での x0–結果相関（random 族、δ=0.1）:

| model | var(x0) の問題間割合 | corr(x0, 結果) 全体 | 問題間 | **問題内** |
|---|---|---|---|---|
| gma | 0.995 | 0.802 | 0.852 | **0.041** |
| lma | 0.936 | 0.659 | 0.721 | **0.162** |
| qwn | 0.861 | 0.277 | 0.351 | **0.132** |
| gpt | 0.503 | 0.298 | 0.321 | **0.273** |

結果の予測力（負の対数尤度、小さいほど良い）:

| model | 定数のみ | x0 のみ | 問題 ID のみ |
|---|---|---|---|
| gpt | 0.693 | 0.647 | 0.345 |
| gma | 0.664 | 0.265 | 0.081 |
| qwn | 0.506 | 0.467 | 0.217 |
| lma | 0.692 | 0.428 | 0.119 |

決定的なのは qwn の x0<0.5 を問題別に開いた表である（n≥14 のみ抜粋）:

| qid | n | 平均 x0 | q |
|---|---|---|---|
| math_test_408 | 32 | 0.038 | 0.000 |
| math_train_497 | 32 | 0.149 | **1.000** |
| math_test_196 | 32 | 0.287 | 1.000 |
| math_train_435 | 14 | 0.408 | **0.071** |
| math_train_77 | 20 | 0.423 | **0.050** |
| math_train_482 | 28 | 0.424 | 0.143 |
| math_train_402 | 27 | 0.412 | 0.444 |
| math_train_440 | 22 | 0.403 | 1.000 |

x0 ≈ 0.40–0.42 の問題群が q = 0.05 から 1.00 まで散らばる一方、x0 = 0.149 の問題は
32 エピソードすべてで正答側に収束する。**x0 は結果を順序づけていない。**

`02_committor.py` が推定しているのは、HMF が定義する「集団状態 x のみを引数とする
一段写像の不安定固定点」ではなく、「問題難度が x0 と結果の両方を駆動する同時分布の
単調要約」である。両者を Δx_c として引き算することはできない。

なお gma は問題間割合 0.995・問題内相関 0.041 であり、この族では**多数派増幅の証拠が
まったく検出されていない**。§2 が報告する gma の committor 曲線 0.11 → 0.98 は、
難問が低 x0 のまま誤答に留まり、易問が高 x0 のまま正答に留まる、という記述に還元される。

対抗論: 「問題難度こそが個体正答率であり、HMF の写像も問題ごとに定義されるのだから、
問題間変動を使うのは正しい」。これは半分正しいが、その場合 x_c は問題ごとに異なる量になり、
プールした 1 本のロジスティックの交点は何の推定量でもなくなる。問題を固定した committor が
必要で、それには問題内の x0 変動が要る。それを十分に持つのは gpt のみ（問題間割合 0.503）で、
その gpt は x0 の 5–95 パーセンタイルが [0.31, 0.66] と最も狭い。**このデータ設計では、
x_c を識別できるモデルが存在しない。**

### A-2. x_c_HMF は w_T = 1 で不連続、それ以外では平坦 — 比較の分解能は 1 ビット

`03_hmf.py` の閾値則を w_T について掃引した（gpt の経験的 P(k)、random 族）:

| w_T | 1.0000 | 1.0001 | 1.001 | 1.01 | 1.05 | 1.159 | 1.332 | 1.712 | 1.99 | 2.01 |
|---|---|---|---|---|---|---|---|---|---|---|
| x_c | 0.500 | 0.2703 | 0.2703 | 0.2703 | 0.2703 | 0.2703 | 0.2694 | 0.192 | 0.192 | なし |

square は w_T ∈ (1, 2) の全域で 0.295、triangular は 0.279。族間の差は 0.27–0.30 の 3% に過ぎない。

原因は同点分岐 `w_T*l == (k-l)` にある。w_T = 1 でちょうど同点が 1/2 で分配されて対称になり、
w_T = 1+ε ではすべて正答側に倒れる。**「w_T=1 なら対称性から x_c=0.500」は理論の予測ではなく、
測度ゼロの分岐条件である。**

帰結が二つある。第一に、§4 の「w_T=1 と Table 3 のどちらが近いか」は、実質「x_c_emp が
0.5 に近いか 0.27 に近いか」という二値判定であり、Table 3 の w_T の連続的な違い
（1.16 対 1.71）は最初から検証対象になっていない。第二に、Table 3 が gpt に w_T=1.159 を
与えている以上、gpt が w_T=1 の予測に一致することは**モデルの一致ではなく不一致**である。
§4 はこれを「gpt, lma: w_T=1 が明確に近い」と、あたかも支持であるかのように記述している。

さらに、P(k) の情報が x_c に入る余地も 3%（0.270 / 0.279 / 0.295）しかない。
x_c が P(k) すなわち α に依存するという主張そのものが、この実装では検出限界以下にある。

### A-3. Table 3 の w_T は過大 — メッセージ水準で測ると 0.94–1.18

HMF に入れる truth asymmetry を、五結合フィットを経由せず生データから直接測った。
各 (エピソード, t, 受信者 j) について、送信者の立場と J のラベルで入力を 4 種に分け、
受信者の次時刻の正誤をロジスティック回帰した（random 族、170 エピソード／モデル、
n_obs ≈ 43,500、`scripts/05_edge_effect.py`）:

logit P(s_j(t+1) = y) = c₀ + θ·1[s_j(t)=y] + c_T⁺·a + c_F⁺·b + c_T⁻·c + c_F⁻·e

a, b = agree ラベル源からの正答／誤答メッセージ数、c, e = disagree ラベル源からの同数。

| model | c₀ | θ | c_T⁺ | c_F⁺ | c_T⁻ | c_F⁻ | **w_T 実測** | w_T Table 3 | λ = c_T⁻/c_T⁺ |
|---|---|---|---|---|---|---|---|---|---|
| gpt | −0.191 | +0.658 | +3.038 | −2.879 | +0.244 | −0.203 | **1.055** | 1.159 | 0.08 |
| gma | −0.535 | +1.276 | +1.215 | −1.031 | +0.675 | −0.525 | **1.179** | 1.712 | 0.56 |
| qwn | +0.593 | +0.389 | +1.702 | −1.891 | +0.501 | −0.509 | **0.900** | 1.332 | 0.29 |
| lma | −0.444 | +0.886 | +1.939 | −1.695 | +0.558 | −0.446 | **1.144** | 1.377 | 0.29 |

全係数の SE は 0.019–0.044。集団状態 x(t) を共変量に加えた頑健版（150 エピソード）でも
w_T は動かない（gpt 1.073、qwn 0.942）が、θ と λ は縮む（gpt θ 0.66→0.36、λ 0.08→0.03;
qwn θ 0.39→0.09、λ 0.29→0.25）。

三点を主張する。

1. **実測 w_T（0.90–1.18）は Table 3（1.16–1.71）より一様に小さい。** gma は 1.71 対 1.18 と
   差が最大で、§4 で「gma は Table 3 が近い」とされた結論はこの過大な w_T に依存している。
   HMF に入れるべきなのは Table 3 の β⁺_T/β⁺_F ではなく、この実測値である。
2. **qwn の w_T は 1 を下回る。** すなわち qwn はメッセージ水準では正答側を優遇していない。
   にもかかわらず qwn の committor は最も truth-seeking に見える。差を作っているのは
   切片 c₀ = +0.593 で、4 モデル中唯一正である。qwn の正答収束は社会的増幅ではなく
   個体の事前正答率に帰属する。
3. **θ は 0 でない（0.39–1.28、統制後 0.09–0.36 程度）。** `03_hmf.py` は自己状態を
   まったく持たない記憶なし写像であり、handoff の「Stage 0: θ=1 の status-quo bias を実装」は
   実際には未実装のまま Stage 0.5 に進んでいる。

限界: この回帰の説明変数（a, b, c, e）は問題難度と相関する内生変数である。x(t) を統制しても
難度が時間変化する成分は残る。したがって係数の絶対値は近似であり、頑健なのは符号と、
統制前後で動かない比 w_T である。

### A-4. qwn の x_c = 0.142 は当てはめの人工物

qwn/random の区間別 committor（δ=0.1、括弧内 n）:

```
0.19(37) 0.92(26) 0.87(39) 0.73(93) 0.69(226) 0.76(337) 0.82(180) 0.93(162) 0.97(100) 1.00(80)
```

単調でない。x0 ∈ [0.1, 0.2) で 0.92 に跳ね、[0.4, 0.5) で 0.69 まで下がり、再び上がる。
下限・上限を自由にしたロジスティック（4 パラメータ）は floor 0.685 / ceiling 1.000 を返し、
**q は [0,1] 上で 0.5 を横切らない**。2 パラメータ版が報告する交点 0.142 は、
下限を 0 に固定した当てはめが床 0.69 を吸収するために置いた点であり、
そこには全データの 3.7% しか存在しない。

§2 はこれを点推定と CI つきで表に載せている。書くべきは「qwn には内部閾値が検出されない」である。
A-3 の測定（w_T = 0.90 < 1、c₀ > 0）はこれと整合する。

### A-5. gma の x_c は両端 2 ビンだけで決まっている

gma/random の区間別 n は 480, 46, 14, 13, 19, 80, 46, 50, 53, 479。中央 8 ビンの合計 321 に対し
両端 2 ビンで 959 を占める。中央部の q は単調でない（1.00, 0.92, 1.00, 0.99, 0.85, 0.94, 0.89）。
下限・上限自由の当てはめでは変曲点 0.190、報告値は 0.285。A-1 と合わせると、
gma の x_c は問題難度の二峰分布の谷の位置を測っている。

### A-6. 報告されている CI は 4–10 倍狭い

問題単位のクラスタブートストラップと、報告されている iid ブートストラップの比較（random 族、δ=0.1）:

| model | x_c | iid CI（報告値相当） | 幅 | 問題クラスタ CI | 幅 | 比 |
|---|---|---|---|---|---|---|
| gpt | 0.494 | [0.477, 0.513] | 0.036 | [0.404, 0.583] | 0.179 | 4.9× |
| gma | 0.285 | [0.251, 0.315] | 0.065 | [0.163, 0.419] | 0.256 | 3.9× |
| qwn | 0.142 | [0.059, 0.206] | 0.147 | [−1.049, 0.367] | 1.416 | 9.6× |
| lma | 0.459 | [0.441, 0.480] | 0.039 | [0.370, 0.564] | 0.195 | 5.0× |

§5 は「同一 (model, question, graph) の 4 エピソードは独立でない」を挙げているが、
支配的なクラスタはエピソードではなく問題である（40 問しかない）。

帰結: §2 のモデル内・グラフ族間の差（gpt square 0.477 対 triangular 0.440 など、n=160）は
主張できない。モデル間の差（gpt/lma 対 gma/qwn）はクラスタ CI でも重ならず、残る。
ただし A-2 により、残ったその差が識別しているのは「0.5 側か 0.27 側か」の 1 ビットである。

### A-7. gpt の x_c は仕様依存で 0.39–0.59 に動く

gpt/random は n(x0 ≥ 0.8) = 2、n(x0 ≤ 0.2) = 2、x0 の 5–95 パーセンタイルが [0.31, 0.66]。
同一データに対する x_c:

| 仕様 | x_c |
|---|---|
| undecided を除外 | 0.391 |
| δ = 0.05 | 0.444 |
| δ = 0.1（報告値） | 0.494 |
| 下限・上限自由の 4 パラメータ | 0.522 |
| δ = 0.2 | 0.585 |

この 0.19 の幅は、比較全体が依拠している 0.5 対 0.27 の間隔（0.23）とほぼ同じである。
§4 の「gpt は |Δ| ≤ 0.06 で w_T=1 に明確に近い」は、仕様選択の幅に埋もれている。

### A-8. undecided を失敗に符号化する非対称性

undecided を落とすと x_c は gpt −0.103、qwn −0.072、gma −0.057、lma −0.029 動く。
gpt の undecided は 27.3% ある。§2 の定義行は q を committor と書いているが、
実際に推定されているのは P(x₈ ≥ 0.5 + δ) であり、正答側と誤答側で扱いが非対称である。
δ 感度は §2 に記載があるので新規の指摘ではないが、非対称性そのものは記載されていない。

## B. 検証して否定された指摘

規範どおり、確認できなかったものも残す。B-1 は本レビューで最初に立てた最有力の仮説であり、
プロトコルを読んで否定された。

### B-1.（否定）「負エッジは反発であり、random 族の HMF には閾値が存在しない」

`k_i = Σ_j |J_ij|` が符号を捨てていること、random 族のスタブの 50.7% が負であることから、
符号を尊重した HMF を実際の J で組んだ。結果は劇的で、random 族には**不安定固定点が
まったく現れず**、単一の安定固定点のみになる（w_T=1 で 0.500、1.712 で 0.657、
F(0.05) = 0.660、F(0.95) = 0.651）。報告値 x_c_HMF = 0.192–0.270 は符号を捨てたことに
完全に依存している、と結論しかけた。

しかしプロトコルを読むと**この前提が誤り**である。`lib/datagen/dynamics.py` の
`_build_inboxes` は J[i,j] の符号でメッセージの**振り分け先ヘッダ**だけを決める:
+1 なら "Messages From Colleagues You Tend to Agree With"、−1 なら "…Disagree With"。
`lib/datagen/samplers.py` の objective モードでは、メッセージ本文は
「私は選択肢 A/B を支持する」と立場を明示する。つまり負エッジは**立場を反転させず、
情報源の信頼度ラベルを下げるだけ**である。

A-3 の回帰がこれを直接確認した: disagree ラベル源からの正答メッセージの係数 c_T⁻ は
4 モデルすべてで正（+0.244, +0.675, +0.501, +0.558、SE ≈ 0.02）。反発ではない。

したがって `k = Σ|J|` は向きとしては正しい。**残る指摘は重みの誤りに縮む**:
負ラベルは減衰して効く（λ = 0.08–0.56、gpt では 12 分の 1）のに、
`k = Σ|J|` はこれを正ラベルと同重量で数えている。正しい有効次数は k_eff = k⁺ + λ·k⁻ であり、
gpt の random 族では平均次数が 3.5 から約 1.8 に下がる。

### B-2.（否定）T=8 で吸収されていないため結果ラベルが信用できない

確かに吸収されていない（t=8 で内部にいる割合は gpt 0.941、qwn 0.676、lma 0.652、gma 0.487。
gpt は 65% のエピソードで t=7→8 に動いている）。しかしラベルは早期に確定している:
内部エピソードの平均ドリフト x₈ − x₅ は −0.013 〜 +0.005、x = 0.5 を t=4 以降に横切るのは
3–6% にすぎない。結論を脅かさない。ただし「合意」「consensus」という語は使えない。

### B-3.（否定）P(k) の構成に誤りがある

`drop_duplicates(subset=["model","graph"])` は J がグラフ ID ごとに固定であることに依存するが、
1,600 ファイル全数のハッシュ照合で 14 グラフすべて J が単一であることを確認した。正しい。

### B-4.（否定）エピソード重みとグラフ重みの P(k) の差が効く

J0–J3 は 160 エピソード、他は 80 で 2 倍の偏りがあるが、P(k) の最大差は 0.007、
平均次数はいずれも 3.50。無視できる。

### B-5.（否定）単票と 5 標本平均で x0 が変わる（`04_compare_rollout.py` の docstring の但し書き）

生標本は {±1} で k=5（奇数）なので、平均の符号は多数決と恒等的に一致する。
差が出るのはパース失敗（0.03%）のみ。この但し書きは実質的に空である。

## C. この検証から得られた変数

規範 11 に従い、指摘を測定可能な量まで落とす。

- **λ（負ラベル減衰）** = c_T⁻ / c_T⁺。有効次数 k_eff = k⁺ + λ·k⁻。実測 0.08–0.56。
  HMF の P(k) はこの k_eff で作り直す。
- **w_T（実測）** = c_T⁺ / |c_F⁺|。0.90–1.18。Table 3 の代わりにこれを使う。
  同点分岐を 1/2 でなく連続化しないと w_T=1 の不連続が残る点に注意。
- **θ（自己保持）** = 自己状態の係数。0.39–1.28（集団状態統制後 0.09–0.36）。
  写像を x(t+1) = θ 項を含む形に書き換える。
- **c₀（個体事前正答率）**。qwn だけ正。x_c が存在するか否かを決めているのは
  w_T ではなくこの項である可能性が高く、HMF に入れる必要がある。
- **問題内 committor**。問題固定効果つきロジスティックで推定する。
  ただし本データでは問題内 x0 変動が不足しており（A-1）、識別できない。

## D. Stage 0.5 の結論として書き換えるべき記述

1. §2 の x_c 表は「committor 閾値」ではなく「x0 と結果の周辺関係の要約」と改める。
   qwn の 2 層（格子）だけでなく、qwn の random も点推定として撤回する（A-4）。
2. §3 の Δx_c 表は、A-2 により「0.5 か 0.27 か」の 1 ビット比較であると明記する。
3. §4 の「gpt, lma は w_T=1 が明確に近い」は、Table 3 が gpt に 1.159 を与えている以上、
   支持ではなく不一致として記述する。
4. §5 の制約に、「x0 が問題難度に内生である」を最上位で追加する。
   これは「P(k) の広がり不足」より上位の制約である。
5. §6 の「HMF の w_T 感度が不連続」は、格子固有ではなく w_T=1 における全族共通の
   不連続であると訂正する。

## E. 限界（本レビュー自身の）

- A-3 の回帰は 170 エピソード／モデルの部分標本であり、random 族のみである。
  係数の絶対値は内生性の影響を受ける（A-3 末尾）。頑健なのは符号と w_T の比。
- 問題内 committor（C 節）は識別不能を示したのみで、代替推定量を提示していない。
- 主観（政治）問題と async 実験は本レビューでも未検証であり、01_findings.md の未実施項目は
  そのまま残る。
- 検証はすべて objective モード、δ=0.1 を基準にしている。δ 依存は A-7・A-8 で扱ったが、
  A-1・A-6 の結論の δ 依存は確認していない。

## F. 主張

このデータで検証したかった命題は「x_c が α（すなわち P(k)）から予測できるか」である。
本検証の結果、その命題は El et al. の公開データでは**検証可能な形をとらない**。理由は三つ重なる。
(i) 被説明変数側で、x0 が問題難度に内生であり committor が識別されない（A-1）。
(ii) 説明変数側で、P(k) が x_c に及ぼす影響が 3% しかない（A-2）。
(iii) 比較の目盛りが w_T=1 の不連続で 2 値化している（A-2）。

したがって Stage 0.5 は「HMF が経験データを再現するか」の検証としては閉じない。
閉じるのは別の問い、すなわち**「HMF に入れるべき係数はメッセージ水準で測れるか」**である。
A-3 はそれが測れることを示した（θ、w_T、λ、c₀ が n_obs ≈ 43,500 で SE 0.02–0.04）。
この測定は Stage 1 の α_eff 測定と同じ設計であり、leave-one-message-out の代わりに
入力の型別カウントを説明変数にした版である。Stage 0.5 の成果はこちらに置き換えるのが妥当である。

x_c の検証は、x0 を問題から切り離して外生的に振る Stage 2 に持ち越される。
その設計では、問題（クレーム）を固定したうえで x0 を割り付けることが必須であり、
本検証の A-1 はその必要性の実証的根拠になる。
