結論を先に書く。**02_review の主結論 3 件（A-1 の内生性、A-2 の不連続、B-1 の棄却）は

## R-1. 誤り: 「モデル間の差はクラスタ CI でも重ならない」（A-6 末尾）

レビュー自身が報告した問題クラスタ CI を突き合わせると:

| 対 | 重なり |
|---|---|
| gpt [0.404, 0.583] vs gma [0.163, 0.419] | **あり** [0.404, 0.419] |
| gpt vs lma | あり [0.404, 0.564] |
| gma vs qwn [−1.049, 0.367] | **あり** [0.163, 0.367] |
| gma vs lma [0.370, 0.564] | **あり** [0.370, 0.419] |
| gpt vs qwn | なし |
| lma vs qwn | なし |

重ならない 2 対はいずれも qwn を含むが、qwn の点推定はレビュー自身が A-4 で
当てはめの人工物として撤回している。**したがって撤回後に残る対比較は一つもない。**
「gpt/lma 対 gma/qwn の差は残る」という A-6 の記述は、自らの CI 表と矛盾している。
これはレビューの結論をむしろ強める誤りである（x_c 表からは何も残らない）が、
記述としては訂正が必要である。

## R-2. 不整合: A-3 の SE は無クラスタ — レビューが A-6 で批判した誤りそのもの

A-3 は n_obs ≈ 43,500 の観測に SE 0.02–0.04 を付したが、観測は 170 エピソード・
40 問にネストしている。問題（qid, 40 クラスタ）でクラスタ頑健化した再計算:

| model | w_T（点推定は不変） | 素の SE 由来の含意 | **クラスタ 95% CI** | Table 3 | w_T=1 を含むか |
|---|---|---|---|---|---|
| gpt | 1.055 | — | [0.996, 1.114] | 1.159 | **含む（境界）** |
| gma | 1.179 | — | [0.731, 1.628] | 1.712 | 含む |
| qwn | 0.900 | — | [0.759, 1.041] | 1.332 | **含む** |
| lma | 1.144 | — | [0.972, 1.316] | 1.377 | 含む |

SE は素の値の 2.5–5 倍になる。帰結は三つ。

1. **「qwn の w_T は 1 を下回る」（A-3 主張 2 前半）は支持されない。** CI は 1 を含む。
   qwn の記述で残るのは切片 c₀ = +0.593（クラスタ SE 0.167、CI [0.27, 0.92]）のみである。
   「qwn の正答収束は増幅でなく個体事前正答率」という帰属自体は c₀ で維持される。
2. **「実測 w_T は Table 3 より一様に小さい」（A-3 主張 1）は生き残る。** Table 3 の値は
   4 モデルすべてで CI の外にある。ただし gma（1.628 対 1.712）と lma（1.316 対 1.377）は
   境界に近く、40 クラスタの CR0 サンドイッチは小標本補正なしでは CI を狭めに出すため、
   wild cluster bootstrap では排除が崩れる可能性がある。「一様に、ただし gma・lma は
   境界的に」と弱めて書くべきである。
3. **新規の含意: 4 モデルすべてで w_T が 1 と区別できない。** A-2 が示したとおり
   x_c_HMF は w_T = 1 で 0.500 → 0.270 に跳ぶ。つまり**経験的な w_T は、写像が
   不連続になるまさにその点の上に乗っている**。硬い閾値則を保つ限り、x_c の予測は
   データが許す w_T の範囲内で定義不能である。02_review の C 節は同点分岐の連続化を
   「注意」として書いたが、これは注意ではなく前提条件である。閾値を滑らかな応答
   （ロジスティック応答そのもの）に置き換えない限り、Stage 0 の HMF 再実装は始められない。

一方、**λ と θ はクラスタ化を生き残る**: λ = 0.080±0.044 (gpt), 0.555±0.078 (gma),
0.294±0.051 (qwn), 0.288±0.041 (lma)、いずれも 1 を大きく下回る。θ も全モデルで
t ≥ 3.4。disagree ラベル正答メッセージの正係数（B-1 の棄却根拠）も維持される
（gpt +0.244、クラスタ SE 0.063）。A-3 の実測で頑健なのは w_T ではなく λ・θ・c₀ である。

## R-3. 過大主張: 「gma では多数派増幅の証拠がまったく検出されていない」（A-1）

文としては正しいが、理由の帰属が欠けている。問題内の x0 変動を測ると:

| model | sd(x0) 全体 | sd(x0) 問題内 | 比 | 問題内 LPM 傾き（クラスタ SE） | t |
|---|---|---|---|---|---|
| gpt | 0.105 | 0.074 | 0.70 | +1.24 (0.21) | **+5.8** |
| gma | 0.433 | **0.030** | 0.07 | +0.22 (0.23) | +1.0 |
| qwn | 0.206 | 0.077 | 0.37 | +0.46 (0.14) | **+3.2** |
| lma | 0.286 | 0.073 | 0.25 | +0.43 (0.13) | **+3.3** |

gma の問題内 x0 変動は SD 0.030 しかなく、検出力が事実上ゼロである。
「証拠が検出されていない」は「増幅がない」ではなく「この設計では検定不能」と読むべきで、
02_review の書き方は後者への誤読を許す。

より重要なのは逆側の事実で、02_review はこれを落としている:
**gpt・qwn・lma では問題内の増幅効果が有意に検出される**（t = 3.2–5.8）。
つまり A-1 が壊すのは「プールした 1 本の曲線の交点」という推定量であって、
問題内の社会的増幅の存在ではない。committor という枠組み自体は問題を固定すれば
生きており、識別できないのは x_c の位置である。02_review の F 節の
「committor が識別されない」は「x_c の位置が識別されない」に狭めるのが正確である。
この区別は Stage 2 の意義に直結する（増幅は既に見えている。測れていないのは閾値だけ）。

## R-4. 識別の注意（A-3 の未記載事項）

受信者 j を固定すると a + b = k⁺_j、c + e = k⁻_j は時刻によらず一定である。
したがって c_T⁺ と c_F⁺ を別々に識別しているのは受信者間・時刻間の次数と構成の変動であり、
受信者内で綺麗に識別されるのは差 c_T⁺ − c_F⁺（メッセージ 1 通の正誤入替の効果）だけである。
比 w_T = c_T⁺/|c_F⁺| は次数と結果の交絡をそのまま受ける。R-2 で w_T の CI が広いのは
標本の問題だけでなく、この識別構造の問題でもある。λ = c_T⁻/c_T⁺ も同型の注意が要るが、
こちらは点推定が 1 から遠いため結論は動かない。

  x0 のみを大差で上回る事実は正しい。qwn の問題別表も正しい。
- **A-2 の不連続**: 同点分岐の算術はレビューの通り。w_T = 1 で厳密に対称
  （F(x) + F(1−x) = 1）、w_T = 1+ε で同点が全て正答側に落ちる。整数次数のもとで

- **A-4 / A-7 / A-8**: 区間別の非単調性、床 0.685、仕様感度 0.39–0.59、undecided の

- **B-1 の棄却**: `_build_inboxes` の読解は正しい。負エッジは立場を反転させず

- **B-5**: k = 5 が奇数なので生標本和は 0 になり得ず、平均符号 = 多数決は恒等。正しい。

## R-7. 本再検証の限界

- クラスタ頑健分散は CR0（小標本補正なし）で、クラスタ数は 40。gma・lma の
  Table 3 境界排除は wild cluster bootstrap での確認が要る。
- A-3 と同一の 170 エピソード部分標本・同一の内生性を引き継ぐ。R-4 の識別問題は
  指摘のみで、解決する設計（エピソード内の入力構成のランダム化）は Stage 2 に属する。
- R-3 の LPM は線形近似であり、傾きの絶対値は committor の勾配と直接比較できない。
  使ったのは符号と有意性のみである。

## R-8. 主張

02_review の破壊的結論 — Stage 0.5 は x_c の検証として閉じない — は、本再検証で
むしろ強まった（x_c 表に残る対差はゼロ、w_T は不連続点上）。弱まったのは建設的結論の
側である: メッセージ水準で測れると主張された 4 係数のうち、頑健なのは λ・θ・c₀ の
3 つで、理論の中心にある truth asymmetry（w_T）は本データの観測変動では 1 から
分離できない。したがって次の一手は 02_review が言う「w_T を Table 3 から実測値に
差し替えて HMF を組み直す」ではない。**閾値則を連続化した上で λ・θ・c₀ を入れた
HMF を組み、w_T は 1 に固定した帰無モデルとの比較として扱う** — w_T の測定自体は、
入力構成を外生化できる Stage 2 の設計に送るのが正しい。
