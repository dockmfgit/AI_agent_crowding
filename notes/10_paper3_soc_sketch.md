# 論文 3 スケッチ: 不応期つき三状態 LLM エージェントと意見カスケードの臨界性

日付: 2026-08-24。状態: スケッチ（着手条件は §6）。優先順位は論文 1（α\*）、
論文 2（正規化）の後。無料の予備解析 3 点（§4）のみ Stage 2 完走後の解析に相乗りさせる。

## 1. 中心の問い（量的形）

意見転換のカスケード（1 個の転換が誘発する転換の連鎖）のサイズ分布と分岐比 σ は、
単体で測った応答係数からどの程度予測できるか。そして注意資源の枯渇・回復を入れた系は、
パラメータ調整なしに σ → 1（臨界）へ自己組織化するか。

## 2. 対応表

| 興奮性媒質 / 森林火災（Bak–Chen–Tang, Drossel–Schwabl） | LLM エージェント系 |
|---|---|
| 感受性（樹） | 通常状態のエージェント |
| 発火（燃焼） | 意見転換 / 新しい主張の発信 |
| 不応（空地、再成長待ち） | 転換直後の再転換・発信の抑制 |
| 延焼 | 転換がメッセージ経由で近傍の転換を誘発 |
| 落雷（遅い駆動 f） | まれに注入される撹乱メッセージ |
| 再成長（p、f ≪ p ≪ 1） | 不応期の回復 / 注意資源の回復 |

理論の背骨: **crowding（資源制約が配線を決める）+ 注意枯渇（資源制約が動力学を
決める）**。Levina–Herrmann–Geisel はシナプス資源の枯渇・回復を遅い変数として
臨界への自己組織化を導いた — 注意資源はその直接の類似物であり、
論文 1・2 と同じ「資源制約」の語彙で三部作が閉じる。

## 3. 既に手中にある材料

- **軟らかい不応性は測定済み**: 変法 B の θ = 2.15（明示自己状態への固着）は
  flip 抑制そのもの。三状態化は仮定でなく実測の延長。
- **恒常性機構の候補も測定済み**: 除算的正規化は k·β をほぼ一定（2.1–2.7）に保つ。
  これは分岐比を次数によらず規格化する調節機構の形をしており、SOC 系が仮定する
  homeostasis を我々は先に実測している可能性がある。
- **分岐比は係数から計算可能**: 静止状態近傍で、1 個の転換が下流 1 本の辺経由で
  誘発する転換確率 ≈ Δσ(β̄(k))。out-degree 分布と合成して σ を閉形式で見積れる
  （scripts/30 の枠組みの小改造）。

## 4. 無料の予備解析（Stage 2 完走後の解析に相乗り、追加呼び出しゼロ）

1. **不応係数の in-situ 推定**: Stage 2 ログの転換系列から
   logit P(転換_{t+1}) に「t で転換した」ダミーを追加（インボックス構成・クレーム FE
   統制、クレームでクラスタ）。係数が負なら行動的不応性の実証。
   El et al. の生データ（05 系スクリプトの拡張）でも同じ推定が可能 — 4 モデル分。
2. **分岐比の実測**: Stage 2 の各 (α, ラウンド) で、転換者の下流に翌ラウンド生じた
   転換数の平均 = σ_emp(α)。§3-3 の係数由来予測と比較。α\* との関係
   （fold 近傍で σ → 1 に近づくはず）も見る。
3. **El et al. 非同期データのカスケード統計**: `external/physics-of-agents/data/async`
   （firing schedule つき）は疎な非同期更新 = 興奮性レジームに近い唯一の既存データ。
   転換カスケードのサイズ分布の形（指数 / 裾）を予備的に見る。

判定: 1 が負で有意、かつ 2 の σ_emp が 0.5–1.5 に入るなら、臨界性の問いは
検定可能な射程にあり、本実験（§5）を設計する価値がある。

## 5. 本実験の骨子（着手時に詳細化）

- **プロトコル**: 同期 8 ラウンドではなく、非同期・疎な更新（毎ステップ 1 体のみ
  発話・更新、El et al. async に準拠）+ まれな撹乱注入（落雷）。時間スケール分離
  f ≪ p を設計変数にする。
- **不応期の実装は二重**: (a) プロトコル課与（τ ラウンド沈黙 — 構成的、τ を掃引）、
  (b) プロンプト誘導（「あなたは直前に立場を変えたばかり」— 行動的、係数を測る）。
  (a) と (b) の一致・不一致自体が結果になる。
- **スケールの戦略は論文 1 と同型**: ミクロ則（不応係数込み）をランダム化プローブで
  測定 → 大 N（10³–10⁴）の雪崩統計は測定済み則のシミュレーションで生成 →
  小 N（32–64）のみ実 LLM で分岐比・小カスケード分布を検証。
  実 LLM で N=32 のベキ則を主張することは最初から放棄する（1.5 桁しかない）。
- **注意枯渇の操作**: 直前ラウンドの処理負荷（受信通数）に応じて次ラウンドの
  受容確率を下げる資源変数を router に実装し、LHG 型の自己組織化
  （σ が 1 に引き込まれるか）を σ の時系列で判定する。

## 6. 着手条件・撤退線

- 着手条件: 論文 1 の Stage 2 解析完了 + 論文 2 の E1 完了後。§4 の判定を通過していること。
- 撤退線 1: 不応係数が 0 と区別できない → プロトコル課与版 (a) のみの理論研究に縮小
  （LLM 固有性が消えるため優先度を下げる）。
- 撤退線 2: σ_emp が全条件で 1 から遠い（< 0.3）→「LLM 集団は深い亜臨界」を
  短報の事実として書き、SOC の枠は撤回する。
- 主張の上限: DS-FFM 自体の厳密臨界性には既知の留保（Grassberger のスケーリング破れ）
  があるため、主張は「SOC の実証」でなく「分岐比・カスケード統計の測定と、
  資源枯渇による σ の自己調節の検証」に置く。

## 7. 三部作としての位置

1. 論文 1: 資源制約が**配線**を決め、集団の転換点 α\* を決める（fold / スピノーダル）。
2. 論文 2: 資源制約が**単体の統合則**（除算的正規化）を決める。
3. 論文 3: 資源制約が**動力学の時間構造**（不応・枯渇・回復）を決め、
   カスケードの臨界性を調節する。
同一の測定様式（ランダム化ミクロ測定 → 閉形式/シミュレーション予測 → 集団検証）を
三度使う。各論文は独立に閉じ、並べると「有限資源の主体からなる集団の統計力学」になる。
