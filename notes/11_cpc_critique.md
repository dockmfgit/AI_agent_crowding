# CPC-MS(Taniguchi et al., RSOS 2025)の批判的検討と三部作による反証可能性

日付: 2026-08-24。対象: "Collective Predictive Coding as Model of Science"
(RSOS 12:241678 / arXiv:2409.00102)。全文は arXiv 版で確認。

## 1. 論文の骨格(公平な要約)

科学を「エージェント集団による分散ベイズ推論」として形式化する枠組みの提案。
各科学者 k は部分観測 o^k から内的表象 z^k を推論し、論文執筆 = P(w|z) からの
サンプリング、査読 = 受理確率が査読者の z に依存する Metropolis–Hastings(MH)型の
受理、として、共有表象 w の事後分布 q(w|{o^k}) が集団レベルで近似されると主張する。
自由エネルギーは「集団正則化 + 個体予測誤差 + 個体正則化」に分解され、
Kuhn 的パラダイム転換は特異モデルの事後分布の不連続ジャンプとして解釈される。
重要な点として、合意 = 真理とは等置せず(個体は不一致のままでよい)、
収束は「エルゴード性・提案の独立性・盲点なし」を条件とする漸近的主張にとどまる。

## 2. 我々の結果と無関係に成立する批判

1. **定量的予測の不在(自認)**: 検証可能な数値予測がなく、§6 で経験的検証の欠如を
   明記。枠組みの反証条件が論文内に定義されていない。
2. **形式化の仕事量**: 自由エネルギー分解は科学活動の再記述であって、
   分解から新しい帰結(既存の科学社会学が出せない予測)が導出されていない。
3. **収束条件の非現実性**: エルゴード性(全仮説が有限確率で提案される)と
   提案の独立性は、出版バイアス・資金制約・Matthew 効果の下で明白に破れるが、
   破れたときに何が起きるかの理論がない。有限時間の議論も皆無。
4. **集約機構の忠実度が未測定**: 「コミュニケーションが分散ベイズ推論を実装する」
   の根拠は MHNG の数理(理想化された受理則)であり、実エージェント(人間・LLM)の
   受理・統合がその形に従うかは測られていない。ここが枠組み全体の急所である。

## 3. 三部作による反証・制約(CPC の前提を LLM で実体化した場合)

CPC-MS 自身が §4 で AI 科学者の参加を論じている以上、「LLM エージェント集団で
前提が成り立つか」は彼らの土俵の内側の問いである。対決点は 4 つ。

### 3-1. 論文 2 → 「通信 = ベイズ的証拠集約」の直接反証

MH 型受理・分散ベイズ推論は、独立な証拠 k 個がログオッズで加算されることを要求する
(尤度の積)。我々の測定は加算則を CV で明確に棄却し、除算的正規化 β/(1+γk) を支持した。
帰結を CPC の言葉で書くと: **k 通の独立報告の実効サンプルサイズは k/(1+γk) ≤ 1/γ で
飽和する**(実測 γ = 0.5–1.3 → 実効 1–2 報告分)。つまり LLM エージェントの通信は、
どれだけ論文・査読を重ねても 1 ステップあたり有効観測 1–2 個分しか事後分布を
更新できない。「反復サンプリングで集団事後分布が真に漸近する」という CPC の
収束機構は、この正規化の下では速度がゼロに漸近する。加えて位置効果と
ラベル減衰 λ(同一内容が情報源ラベルで最大 12 分の 1)は、受理確率が証拠の
尤度比でなく提示形式に依存することを示し、MH 受理の前提を破る。

### 3-2. 論文 1 → 「批判的対話がバイアスを修正する」の境界条件

CPC は「個体バイアスは査読・追試を含む批判的対話で修正される」とする。
我々の枠組みはこの主張が成り立つ**境界を計算する**: α < α\* では誤答側合意の
吸収域が存在し、多数派が誤っている初期条件からの対話は誤りを修正せず**固定する**。
自己修正性は対話の量でも多様性でもなく、注意容量(資源パラメータ)の閾値 α\* で
決まり、α\* は単体係数から閉形式で予測できる。Stage 2 が予測どおりなら、
「対話による修正」は無条件の性質ではなく α > α\* の相にのみ存在する性質になる。
さらに E[K] = (log N)/α は、共同体を 10 倍にしても 1 人が統合できる情報源が
2–3 人分しか増えないことを意味し、「共同体全体としての事後分布統合」の帯域が
対数でしか伸びないという定量的制約を CPC のスケーリング的楽観に課す。

### 3-3. 論文 3 → エルゴード性の実測

CPC の収束はエルゴード性に条件づけられているが、破れの測度を持たない。
我々の θ(変法 B で 1.9–2.2)は、自己の直前の立場が約 10 通の反対メッセージに
相当する固着であることを示し、混合時間を桁で引き延ばす。論文 3 の分岐比 σ と
カスケード統計は、探索が実際上凍結している(亜臨界)か、同調暴走(超臨界)かを
測る — どちらの相でもエルゴード的な仮説空間の探索は成立しない。
CPC が Kuhn 的転換を「事後分布の不連続ジャンプ」と解釈する部分は、
カスケードサイズ分布の裾として初めて操作化・検証可能になる。

### 3-4. AI 科学者論(§4)への反証: LLM は多様性を足さない

CPC は「AI は人間と異なる θ^k を持ち多様性を増やし、バイアスを減らし得る」とする。
我々の測定はこの想定の逆を示唆する: 複数の LLM(gpt/gemma/qwen/llama)が
**共有された系統バイアス**(極性効果 = TRUE 側主張の一様な優位、正規化、位置効果、
SUPPORTS クレームへのほぼ一様な高信頼)を持つ。LLM エージェントの複数投入は
独立サンプラーの追加ではなく、相関したバイアスの複製であり、CPC が要求する
提案の独立性をむしろ悪化させる。これは論文 2 の多モデル測定(γ・極性の
モデル間分布)で直接定量化できる。

## 4. 公平性のための注記(反証にならない部分)

- CPC の「合意 ≠ 真理、個体は不一致のまま」という規定は我々の枠組みと整合的で、
  対決点ではない。
- 「均質な共同体でバイアスが蓄積する」という彼らの定性的予想は、我々の h_q・
  極性の知見とむしろ整合する。
- CPC は規範的・理想化モデルなので、「実装がずれている」という反論には
  「理想からの逸脱は雑音」と応じ得る。我々の反証が効くのは、(a) 彼ら自身が
  AI 科学者への適用を主張している点、(b) 逸脱が雑音でなく**構造的**
  (正規化・閾値 α\*・固着)で、収束主張の速度・可否そのものを変える点、の二点による。

## 5. 論文側への反映

- 論文 1 §6 の関連研究に 1 文: CPC-MS を「集団を理想化ベイズ推論として記述する
  規範的枠組み」として引き、我々の結果を「その十分条件(加算的集約・エルゴード性・
  無条件の自己修正)が LLM 共同体で成り立つ範囲を測定した」と位置づける。
  反証の言葉は使わず、境界条件の測定として書く(規範 6)。
- 論文 2 の Discussion に実効サンプルサイズ ≤ 1/γ の含意を 1 文
  (「分散ベイズ推論としての通信」の帯域上限)。
- 論文 3 の動機づけに CPC のエルゴード性条件を引用。
