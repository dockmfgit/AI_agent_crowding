# α* の解析的導出と数値検証

日付: 2026-08-23。目的: Stage 2 の主予測である双安定消滅点 α* を、数値掃引でなく
閉形式のチェーンから導く。コード: `scripts/30_alpha_star_analytic.py`。
図: `fig/alpha_star_analytic_validation.png`。

結論を先に書く。**α* は三つの閉形式部品 — 平均次数 K̄(α) = (1/α)ln(1+α(N−1))、
ガウス平滑化した 1 次元写像 G(x; K)、その fold 条件 — の合成として書け、
厳密数値（P(k) 全和の fold）に対し中央値 2.1%（厳密 E[K] 反転）/ 6.4%（完全閉形式）で
一致する。**同じ閉形式は結合の k 依存（飽和則）も係数の置換だけで扱える。
これで論文の主張「臨界注意容量は α から解析的に予測できる」が、数値表でなく式として立つ。

## 1. 記号の整理と厳密な出発点

更新則（Stage 1 実測形）: logit P(次に正答側) = c₀ + θ·1[自己=正答側] + β_T l + β_F (k−l)。
以下の再パラメータ化がすべての基礎になる:

- **h = c₀ + θ/2**（対称性を破る場。θ の指示関数は定数場 θ/2 + 対称項に分解される）
- **β̄ = (β_T − β_F)/2**（入力 1 本あたりのスイング）
- **δ = (β_T + β_F)/2**（入力 1 本あたりのドリフト。k 本で kδ の場を作る）

これで m ≡ β_T l + β_F(k−l) = kδ + 2β̄(l − k/2)。厳密な HMF は

F(x) = Σ_k P_α(k) E_{l∼Bin(k,x)} [ x σ(h + θ/2 + m) + (1−x) σ(h − θ/2 + m) ]

で、α* はその内部不安定固定点が消える α（fold）である。ここまでは数値でしか扱えない。

## 2. 部品 1: 平均次数の閉形式

受容過程（r 本受容済みで次を e^{−αr} で受容）の決定論的連続極限 dK/dm = e^{−αK} を
m = N−1 まで積分すると

**K̄(α) = (1/α) ln(1 + α(N−1))**

N=32 で厳密再帰の平均に対し −3%（α=0.3）〜 −11%（α=2）。漸近形 (log N)/α の
有限 N 版である。バイアスの向きは一定（Jensen 不等式: E[e^{−αK}] ≥ e^{−αE[K]}）なので、
精度が要る場面では厳密再帰の E[K]（これも閉じた計算）で置換できる。

## 3. 部品 2: 平滑化 1 次元写像

二項和をガウス–ロジスティック近似 E[σ(Z)] ≈ σ(μ_Z / √(1 + (π/8)σ_Z²))（Z 正規）で
閉じ、次数を K̄ で置換すると、1 次元の閉形式写像が得られる:

G(x; K) = x σ(z₊) + (1−x) σ(z₀)
z_s = [ (h ± θ/2) + Kδ + 2β̄K(x − 1/2) ] / √(1 + (π/8)·4β̄²K x(1−x))

結合が k に依存する場合（例: divisive β(k) = β/(1+γk)）は β̄, δ に g(K) を掛けるだけで
同じ形が使える。**α* = G の fold**: G(x) = x と G′(x) = 1 の連立が解を失う点。
実装上は「G が双安定になる最小の次数 K\*」を求め、K̄(α) = K\* を α について解く。

## 4. 解釈可能な極限: λ(K) = 1

場の補正を落とした対称点 x = 1/2 での線形利得は

λ(K) = [σ(z₊) − σ(z₀)]  +  2β̄K·σ̄′ / √(1 + (π/8)β̄²K)

第 1 項が**自己保持利得**（θ が作る）、第 2 項が**社会的増幅利得**。分母は平滑化
（入力ゆらぎ √K）による自己制限で、社会項は β̄²K ≫ 1 で √(8K/π) 的にしか伸びない。
双安定の必要条件は λ > 1 であり、「次数が減ると社会的増幅が落ちて双安定が消える」
という α* の機構はこの式が担う。ただし実測パラメータでは場 h_eff = h + Kδ が
小さくないため fold は中心から離れて起き、**λ = 1 は α* を 30–90% 過大に見積もる**。
機構の説明は λ 式、予測値は fold（§3）、という二層で使い分ける。

なお実測変法 A では δ = (0.419 − 0.568)/2 = −0.075 < 0 であり、K ≈ 9.7 で
h + Kδ = 0 と場がほぼ打ち消される。h > 0 にもかかわらず低 α 側で双安定が保たれるのは
このドリフトによる場の遮蔽が原因である — 解析形にして初めて見えた構造。

## 5. 検証

厳密数値（P(k) 全和、α 刻み 0.02）との比較。定数則 9 組 + 飽和則 2 組:

| パラメータ | 厳密 α* | G-fold（厳密 E[K]） | G-fold（完全閉形式） |
|---|---|---|---|
| h=.10 θ=.6 β̄=.5 | 0.62 | 0.640 | 0.593 |
| h=.10 θ=.6 β̄=1 | 1.40 | 1.415 | 1.248 |
| h=.30 θ=.6 β̄=1 | 1.12 | 1.172 | 1.048 |
| h=.70 θ=.6 β̄=1 | 0.84 | 0.882 | 0.804 |
| h=.10 θ=0 β̄=1 | 1.18 | 1.199 | 1.070 |
| h=.10 θ=2 β̄=.5 | 0.90 | 0.899 | 0.818 |
| h=.30 θ=2 β̄=1 | 1.54 | 1.568 | 1.372 |
| **変法 A 実測（定数）** | 0.42 | **0.435**（K\*=6.4） | 0.409 |
| **変法 B 実測（定数）** | 0.46 | **0.470**（K\*=6.1） | 0.440 |
| **変法 A 実測（divisive）** | 0.46 | 0.502（K\*=5.9） | 0.469 |
| **変法 B 実測（divisive）** | 1.26 | **1.284**（K\*=3.2） | 1.141 |

中央値相対誤差: 厳密 E[K] 反転で 2.1%、完全閉形式で 6.4%。最悪は変法 A divisive の 9%。
アーム B の則判別予測（0.46 対 1.3）も閉形式のまま再現される。

## 6. Stage 2 への含意

- アーム A の解析予測: **α\* = 0.435（K\* = 6.4）**。読み替えると「31 人の候補のうち
  平均 6.4 人しか参照しなくなった時点で、誤答側合意の吸収域が消える」。
- アーム B: 定数則なら K\* ≈ 6.1（α\* 0.47）、飽和則なら K\* ≈ 3.2（α\* 1.28）。
  判別の物理的意味は「双安定を支えるのに必要な最小参照人数」の違いとして書ける。
- 観測 α\*_emp との比較では、本閉形式の誤差（〜5%）は committor 推定の統計誤差より
  小さい見込みで、比較のボトルネックにはならない。

## 7. 限界

- 次数を平均で閉じており Var[K]（有界だが非ゼロ）を落としている。P(k) の裾は
  厳密 HMF との 2–5% 差の主因。
- ガウス–ロジスティック近似は小さい k（≤2）で粗い。K\* が 3 前後に来る飽和則で
  誤差がやや大きい（9%）のはこのため。
- HMF 自体の限界（クラスタリング・相関・有限 N ゆらぎの無視）はそのまま残る。
  Stage 2 の観測 α\*_emp は有限 N でクロスオーバーに鈍るため、比較は
  「鋭い点対点」ではなく「予測点が経験的遷移帯の中に入るか」で行うこと。
- λ = 1 判定は定量には使えない（30–90% 過大）。論文では機構の説明にのみ使う。
