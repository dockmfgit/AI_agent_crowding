# Stage 0.5 findings — El et al. 公開データ再解析（事実のみ）

日付: 2026-08-22。対象: 客観問題 6,400 集団（4 モデル × 40 問 × 10 グラフ × 4 エピソード）。
定義: x(t) = (1/N) Σ_i 1[sign(ō_i(t)) = y_gt]、ō_i = 5 サンプル平均。既定 δ = 0.1。
成果物: `data/groups.parquet`, `results/{committor_bins,xc_empirical,xc_hmf,xc_rollout,comparison}.csv`, `fig/`。

## 1. x0 の分布と committor が引けた範囲

全体では x0 は広く分布（mean 0.507, std 0.287; x0<0.2 が 18.1%, x0≥0.8 が 17.5%, [0.4,0.6) は 36.4%）。
ただし**分布の形はモデルごとに全く異なる**:

- gpt: 0.5 集中（std 0.105）。**ビン 0–0.1 と 0.9–1.0 は n=0**（random）、0.1–0.2 も n=2。committor が引けるのは実質 x0 ∈ [0.2, 0.8]。
- gma: 両端二峰（std 0.433）。random ではビン 0–0.1 に 480、0.9–1.0 に 479、中央ビン（0.2–0.5）は n=13–19 と薄い。格子ではビン 0.3–0.4 が **n=0**。
- qwn: 0.57 中心のやや右寄り分布（std 0.206）。左端ビン n=37（random）、格子では左端 n=4–5。
- lma: ほぼ一様（std 0.286）。全ビン n≥46（random）。

端ビンの committor（random, δ=0.1）: gma q(0–0.1)=0.113, q(0.9–1)=0.983;
qwn q(0–0.1)=0.189, q(0.9–1)=1.000; lma q(0–0.1)=0.082, q(0.9–1)=1.000。

undecided 率（δ=0.1）: gpt 25.2%, gma 3.6%, qwn 8.2%, lma 6.4%。

## 4. w_T = 1 と Table 3 のどちらが近いか

モデルにより分かれる:

- **gpt, lma: w_T=1 が明確に近い**（|Δ| ≤ 0.06 vs 0.16–0.22）。empirical x_c は 0.44–0.51 で 0.5 近傍。
- **gma, qwn: Table 3 の w_T が近い**（gma |Δ| 0.04–0.10 vs 0.22–0.32; qwn |Δ| 0.13–0.20 vs 0.34–0.42）。
  ただし qwn は Table 3 でも Δ が −0.13〜−0.20 残り、どちらの w_T も empirical を再現しない。

三結合 rollout は gpt・lma では |Δ| ≤ 0.09 と最も近いか同等だが、gma・qwn では
x_c_rollout ≈ 0.5 前後にとどまり、empirical（0.08–0.29）から 0.2–0.47 離れる。
つまり gma・qwn では、論文の三結合フィット則の rollout 自体が実データの正解側バイアスを過小に再現する。

## 5. データの制約

- **P(k) の広がり不足**: random は k=0–9（平均約 3.5、質量の 66% が k=2–4）、square は k∈{2,3,4}、
  triangular は k∈{2,3,4,6}。格子は非周期境界のため δ 関数ではないが、いずれも次数の裾がなく、
  HMF の k 依存構造を検証できる範囲が狭い。
- **負エッジ**: random グラフのエッジの 50.3% が負。HMF 閾値モデル（仕様どおり k_i=Σ|J_ij|、全入力を引力扱い）
  はこの符号構造を完全に無視する。square/triangular は正エッジのみでこの問題はない。
- **x0 の偏り（モデル依存）**: gpt は端ビンが空で x_c=0.5 近傍の局所情報しかない。gma は逆に中央が薄い。
  層によっては（gma 格子のビン 0.3–0.4 など）n=0 のビンがある。補間はしていない。
- **エピソード間のばらつき**: 同一 (model, question, graph) の 4 エピソードは独立でない
  （bootstrap は集団単位でリサンプルしており、この相関は CI を過小評価し得る）。
- パース失敗は無視できる規模（生サンプル 9,216,000 中 0 が 2,804 個 = 0.03%、sign(ō)=0 の agent-step 104 個）。

## 6. 期待と違った点・解析できなかった点

- **「低ランク 6」グラフ族は存在しない**。データにあるのは符号付きランダム 12（J0–J7, Jf0–Jf3）、
  square、triangular のみ。層別は 3 族で実施。
- **x0 が 0.5 集中という事前予想は全体としては外れ**（プール std 0.287）。ただし gpt 単体では予想どおり
  0.5 集中。「高エントロピー問題選定 → x0≈0.5」はモデル間で共有されない（probe は GPT ベースの選定らしく、
  他モデルには転移していない）。
- **HMF の w_T 感度が不連続**: 次数が小さい整数（k≤9）のため、閾値 w_T·l > k−l は w_T が (1,2) の
  範囲では格子でほぼ同一の解を与える（square の x_c_HMF=0.295 が全モデル共通になるのはこのため）。
  w_T の連続的な違い（1.16 vs 1.71）が x_c_HMF にほとんど反映されない層がある。
- w_T=1 の HMF は構造によらず x_c=0.5 を返すため、この検証枠組みでは「x_c_emp が 0.5 からどれだけ
  ずれるか」だけが判別情報であり、P(k) の情報は Table 3 側の w_T 経由でしか効いていない。
- HuggingFace 版データセット（agent-opinions）には qid・graph_id・メッセージ本文が含まれず、
  再解析は GitHub リポジトリ内の生 JSON で行った（両者は同一実験の生成物）。
- 未実施: 主観（政治）問題、async 実験、五結合則での rollout（couplings.json の五結合は
  correct-neighbor 依存の drive 分解が必要で、`discrete_rollout` の k∈{1,3} 設計では直接は回せない）。
