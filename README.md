# AI_agent_crowding

Code, data, and working notes for:

> M. Fukushima, *Claim-induced fields and message-capacity limits set the
> transition points of collective truth-finding in language-model networks* (2026).
> arXiv: [to be added]

Collectives of LLM agents exchange messages and update binary judgments on
CLIMATE-FEVER claims. The interaction network is generated by a crowding
process (accept a further source with probability e^(-alpha r)); the paper
asks how far the collective outcome is computable in advance from
single-agent measurements alone, with nothing fitted to collective data. The
main prediction, its decision criteria, the polarity hypothesis table, and the
claim-selection rule of the calibration campaign were pre-registered to file
before the corresponding data were collected.

The theory builds on the synaptic crowding model of
[Fukushima, Sci. Rep. 16:11748 (2026)](https://doi.org/10.1038/s41598-026-47213-2).

## Layout

- `scripts/` — measurement, collective engines, analysis (numbered in
  execution order; `stage1_lib.py` holds the shared prompt scaffold and
  ollama client).
- `results/` — CSV tables backing every figure and number in the paper.
  `r1_*`, `r23_*`, `r34_*`, `r4_*`, `r5_*`, `r6_*`, `r8_*` are the outputs of
  scripts 50–57 (identified response fits, fixed points, surrogate rollouts,
  outcome distributions, prediction intervals, fold precision, 70B intervals);
  the pre-registration files and their SHA-256 values are recorded in `notes/`.
- `data/` — raw JSONL call logs and per-episode JSON (stance histories, full
  message texts, graphs, seeds, prompt hashes). Large; see MANIFEST.md.
- `notes/` — working records: stage instructions, results reports,
  independent verification notes, pre-registration records with file hashes.
- `manuscript/` — LaTeX sources and figures.
- `fig/` — exploratory figures produced during the analysis.

The public dataset of El et al. (arXiv:2608.16578) is **not** redistributed
here; scripts that reanalyze it expect it under `external/` from its
original source.

## Reproduction

Serving: [ollama](https://ollama.com) with `llama3.1:8b` (Q4_K_M),
`qwen3:8b` (tag 500a1f067a9f, `think:false`), `llama3.3:70b`;
temperature 0.7; seeds recorded per call. Analysis: Python 3 with numpy,
pandas, scipy, statsmodels, matplotlib. Figures 1, 3 and 5 regenerate from
`results/*.csv` via `scripts/40_manuscript_figs.py`, Figures 2, 4, 6, 7 and
SI Fig. S1 via `scripts/54_figs_revised.py`; every `results/` table
regenerates from `data/` via the numbered scripts (`scripts/hmf_lib.py` holds
the mean-field map, identified designs, and fixed-point search).
